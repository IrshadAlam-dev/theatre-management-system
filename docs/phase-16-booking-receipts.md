# Phase 16: booking receipts

Each item in **My bookings** has a **Print receipt** action. The print-friendly
receipt includes the booking reference, booking date, showtime, theatre and
screen, seats, booking and payment status, total, and cash receipt reference
when available. It also includes the admin ID and time for recorded cash
confirmations and refunds.

The receipt is a view of the booking and manual cash records in this application;
it is not proof of a card transaction or cash transfer. Browsers may require
pop-ups to be allowed for the print window.
